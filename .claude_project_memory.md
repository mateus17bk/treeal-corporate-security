App Django localizado em `/root/corporate-security-app/` desenvolvido para consulta de CNPJs, enriquecimento cadastral (Multi-API Fallback: BrasilAPI, Minha Receita, CNPJ.ws), detecção forense de métodos de pagamento (Pix, gateways), análise de risco/fraudes integrada com o Portal da Transparência da CGU (CEIS/CNEP), suporte a Agente de IA do Google (Gemini 2.5 Flash), tela de cadastro de usuários vinculada ao banco de dados e design system Helios/Google Stitch em tom escuro com vidro fosco (glassmorphism). Pronto para deploy na OCI e versionado no repositório GitHub `rtadewald/skills`. Relacionado com [[treeal-collector-project]] e [[zabbix-downdetector-setup-guide]].
